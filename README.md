# Bali Květen 2027 — Plánovač výletu

Interactive trip planner for a 13-night Bali trip (May 9–22, 2027) for 2 adults.
Czech language UI, tailored to nature + local food + authentic culture.

## Features

- **Overview** — flights, route, budget tracker
- **Lodging picker** — tip vs alternative villas with Airbnb links, ratings, photos
- **Must-see** — beaches, waterfalls, temples, hikes, snorkeling — prioritized for nature lovers
- **Must-eat** — warungs, street food, grilled fish, babi guling, local coffee
- **Autentická kultura** — temple etiquette, cooking class, batik workshop, subak walks, canang sari
- **Day-by-day itinerary** — 16 days with food tips, logistics, and transfer details
- **Logistics** — transfers, budget estimates, practical info
- **Co vynechat** — tourist traps, overpriced attractions, Instagram scams

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5199`.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Lucide React icons
- No backend, no database — static SPA

## Notes

- Airbnb prices from October 2026 search for May 2027 dates
- Exchange rate: 23 CZK/USD
- AUH–DPS connection assumed typical Etihad routing
